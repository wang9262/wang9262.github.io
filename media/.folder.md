# Media Assets

## Role
Stores all static media files (images, videos, gifs) referenced in blog posts.

## Structure
- Files are organized by post slug: `public/media/{slug}/`
- Filename convention: `{slug}-{index}-{originalName}.{ext}`

## Maintenance
- Managed by `scripts/organize-media.js`
- Validated by `scripts/validate-media.js`
- Do not manually add files here without running the organization script.
