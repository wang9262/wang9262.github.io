# 目录说明: public/styles

## 1. 地位 (Position)
本目录存放需要被公开访问、或需要注入到第三方 iframe 中的 CSS 样式文件。

## 2. 逻辑 (Logic)
*   **独立性**: 此处的 CSS 文件通常不经过构建工具的哈希处理（在 Data URI 注入场景下），或作为静态资源直接引用。
*   **特定用途**: 主要用于无法通过 Tailwind 或主站 CSS 控制的外部组件样式覆盖。

## 3. 约束 (Constraints)
*   **命名**: 保持文件名清晰，表明用途。
*   **维护**: 修改此处文件后，需检查依赖此文件的组件（如 `Giscus.astro`）是否需要同步更新逻辑。

## 4. 成员 (Members)
*   `giscus.css`: Giscus 评论系统的 **浅色模式** 自定义主题。
    - 强制透明背景，适配站点 Light 主题，移除 Giscus 默认边框和阴影。
*   `giscus-dark.css`: Giscus 评论系统的 **深色模式** 自定义主题。
    - 适配站点 Dark 主题，调整输入框背景为深灰 (`#0d1117`)，增强对比度。
